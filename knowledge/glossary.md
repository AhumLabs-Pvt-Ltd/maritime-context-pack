# Glossary

Short definitions in our own words. Where a term comes from a convention, the convention
is named so you can check the official text.

| Term                         | Meaning                                                                                                                                                    |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Anniversary date             | The day and month of each year that matches the certificate's expiry date. Annual and intermediate survey windows are counted from it.                     |
| Annual survey                | A survey done every year within a window around the anniversary date to confirm the ship still meets the certificate's requirements.                       |
| Class society                | See [roles.md](roles.md).                                                                                                                                  |
| Convention                   | An international treaty, usually adopted through IMO, that flag states make part of their national law. Examples: SOLAS, MARPOL, Load Lines.               |
| DOC                          | Document of Compliance. Issued to a company (not a ship) under the ISM Code, confirming its safety management system meets the Code.                       |
| Dry-docking                  | Taking a ship out of the water so the bottom can be inspected and repaired.                                                                                |
| Endorsement                  | A signed and stamped entry on a certificate recording that a required survey was completed.                                                                |
| Flag state                   | See [roles.md](roles.md).                                                                                                                                  |
| Freeboard                    | The vertical distance from the waterline to the freeboard deck. Load line rules set the minimum.                                                           |
| Gross tonnage (GT)           | A measure of a ship's overall internal volume, used to decide which rules apply. Not a weight.                                                             |
| HSSC                         | Harmonized System of Survey and Certification. Aligns survey dates and validity periods across the main IMO certificates so they can be surveyed together. |
| IMO                          | International Maritime Organization, the UN agency for shipping safety and pollution prevention.                                                           |
| IMO number                   | A permanent 7-digit ship identifier with a check digit, shown as `IMO` followed by the digits. It stays with the ship for life.                            |
| Interim certificate          | A short-term certificate issued while the conditions for a full-term certificate are being met, for example a new ship or new manager under the ISM Code.  |
| Intermediate survey          | A more thorough survey held once in a 5-year cycle, around the second or third anniversary date, in place of one annual survey.                            |
| ISM Code                     | International Safety Management Code. Requires companies and ships to run a documented safety management system.                                           |
| Load line                    | Marks on the hull showing the deepest a ship may be loaded in each season and zone.                                                                        |
| MARPOL                       | International Convention for the Prevention of Pollution from Ships. Annex I covers oil.                                                                   |
| Non-conformity               | A finding during an audit that something does not meet the requirements, with a deadline to fix it.                                                        |
| Oil Record Book              | A logbook that records oil and oily-waste operations on board, required by MARPOL Annex I.                                                                 |
| PSC                          | Port State Control. See [roles.md](roles.md).                                                                                                              |
| Recognized organization (RO) | An organization, usually a class society, that a flag state authorises to survey and certify ships on its behalf.                                          |
| Renewal survey               | The survey done before a certificate expires so that a new one can be issued.                                                                              |
| SMS                          | Safety management system: the company's documented procedures under the ISM Code.                                                                          |
| SOLAS                        | International Convention for the Safety of Life at Sea.                                                                                                    |
| Statutory certificate        | A certificate required by a convention or by flag state law, as opposed to a class certificate required by a class society's rules.                        |
| Synthetic data               | Made-up data that looks realistic but describes no real ship, company or person. The only kind of data allowed in Ahum repositories.                       |
