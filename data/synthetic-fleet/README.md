# Synthetic fleet

`fleet.json` holds 20 invented vessels with 5 certificates each. It is generated by
`scripts/generate-fleet.ts` and is deterministic.

```sh
pnpm generate:fleet                     # default reference date 2026-11-01
pnpm generate:fleet --as-of 2027-03-01  # same fleet, dates shifted around a new date
pnpm validate                           # check it against the schemas
```

The generator aims for about 70% valid certificates, 18% expiring within 90 days and 12%
expired, measured from the reference date. About half the registry certificates have no
expiry date (permanent registration); the rest are provisional.

## How it stays synthetic

- IMO numbers start with `IMO0` and fail the IMO check digit, so they cannot be real.
- Vessel names start with `SYN`. Owners, managers, class societies and the registry are
  named "Synthetic ...".
- Every vessel and certificate has `"synthetic": true`.

Do not edit `fleet.json` by hand: a test checks that it matches the generator output.
